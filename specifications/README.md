# Working specifications

Working Draft v0.4 is the current experimental dual-instrument specification. The [Gate A contract](../docs/MG-001_GMG-A_gate_a_contract_v0.4.md) and [Gate B laboratory](../experiments/gate-b/README.md) provide the verified simulation baseline. For post-merge milestones, use the [development status](../docs/development-status.md). The revision records below preserve their original design context.

The public [GMG-A demonstrator](https://ascendancy-systems.github.io/meta-gauge/) continues to implement the v0.2 spatial model. MG-001's bounded qualitative EF-001 assessment is recorded in the [operational record](https://github.com/Ascendancy-Systems/.github/blob/main/profile/META-GAUGE.md).
